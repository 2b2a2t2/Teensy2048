### Cross-cutting modules (shared options across POLY/MONO engines)

- [ ] **Articulation-state engine** — 4-state machine (legato/tenuto/staccato/marcato) with transition weights; generates articulation pattern first, then fills pitch/timing. Shared by LEAD (sax/trumpet fall/doit/shake), POLY STAB/COMP (horn stabs, piano comp), BASS (walking articulation). Articulation page on M2 for applicable types.
- [ ] **Interval-transition grammar** — weighted interval table (1st/2nd order: last interval + direction → next interval + direction). Hard constraints: leap recovery (stepwise opposite), tendency-tone resolution, no same-direction leap chains. Style tables (JAZZ/BLUES/CLASSICAL) in PROGMEM (~120 bytes). INTERVAL STYLE knob morphs stepwise ↔ leap-heavy. Used by LEAD, BASS WALKING, GNR8.
- [ ] **Two-level contour** — bar-level ARCH/DESC target + step-level local walk with pull toward bar target (overshoot/enclosures). ARCH/DESC = structural tones per bar; WALK = local layer. No new knobs, structural change in Gen.cpp. Shared by LEAD, BASS WALKING, GNR8.
- [ ] **Cadence-aware phrasing** — feed Key4 cadence scores (CADENCE term, ii–V/V–I at bar ends) into rest/articulation/density generators: raise rest prob after stable-tone cadence, lower mid-phrase. PHRASE knob (0–100) scales cadence clustering. Shared by LEAD, BASS, any phrasing engine.
- [ ] **Directional memory / balance** — running up/down accumulator over sliding 4–8 steps; threshold exceeded → bias toward opposite direction. BALANCE knob (0–100) controls pull-back. Shared by LEAD, BASS WALKING, any melodic line.
- [ ] **Starting-note grammar** — phrase-open constraint: START ∈ {stable (1/3/5), tension (2/4/7), any}. One-shot at phrase boundary. Shared by LEAD, BASS.
- [ ] **Register-band** — moving pitch window (e.g., 5th wide) whose center drifts by slow LFO/rule (center up step every 4 bars, down third every 8). Notes chosen freely within band; band constrains, FOLLOW resolves. Shared by LEAD, BASS, POLY counterline.
- [ ] **Rhythm templates** — clave/tresillo families, Euclid + syncopation transform, tresillo/clave families. Shared by GNR8, ARP, BASS RIFF, POLY COMP/HITS, STRUM, COMP stabs. RHYTHM TEMPLATE selector + SYNCOPATION knob.
- [ ] **Density envelope** — shaped note-count curve over pattern (e.g., 1,3,6,2 notes/bar following a shape), not flat FILL. DENSITY as structural gesture. Shared by GNR8, LEAD, POLY COMP, any engine.
- [ ] **Approach / tendency resolution** — chromatic/scale approach into target note (chord root, next chord tone). Shared by BASS APPROACH, LEAD tendency tones, FOLLOW MAP.
- [ ] **Corpus / persistent pool** — CORPUS: embedded style transition table (style fingerprint), CORPUS selector + COHERENCE knob. POOL: persistent 64-step pitch pool, RESEED gesture, FILL/PROB/TIE shape expression. ALGO = CORPUS/POOL in GNR8.
- [ ] **Factor Oracle / motif recombination** — buffer recent input, build suffix graph, playback walks forward links (coherent) or suffix jumps (recombined). COHERENCE, LENGTH, FREEZE. Extends HAND recording.
- [ ] **Contrapunk RULES MAP** — FOLLOW MAP = RULES: score candidates against voice-leading ruleset (no parallel 5ths/8ves vs feeder, resolve tendency tones, stepwise preference). Replaces NEAR/ROOT/DEG/IVL/CT/GD when engaged.
- [ ] **SCRAMBLE hybridization** — M2 page: SRC A / SRC B (tracks/slots), BLEND (0=A, 100=B, mid=interleave), RESEED. Two-source segment recombination.
- [ ] **Call-response scheduling** — machine↔human (listen window, quote/vary input, prompt on silence) and machine↔machine (track A phrase → track B response → track A response). Short-term memory of recent input. Builds on HAND timing.
- [ ] **Silence-first / gap-fill** — generate rest pattern first (rhythmic grammar / Euclid), then fill sounding steps. SILENCE_FILLER role: detects gaps in feeder, fills with role (stab/pad/riff). UNISON_DOUBLER: mirrors feeder transposed/thickened.
- [ ] **Harmonic rhythm** — POLY track generates *when* chords change (1/bar, 2/bar, 3+1, late) not *what* they are. Acts on another track's chord timeline (HARM/KEYMODE4).
